# Fahmi Zulkarnain Habib's Portfolio Site
## Description
This is a static portfolio site that I run on my github pages. This project is my first portfolio project that I built myself using React.js with Vite and TypeScript and TailwindCSS.

## How to Use This Project
Run shell below to download the project:
```bash
git clone https://github.com/zulkou/zulkou.github.io
cd zulkou.github.io
```
To run the project locally, run:
```
npm run dev
```
